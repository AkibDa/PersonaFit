# PersonaFit: Your Personalized Fitness Companion

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://personafit.streamlit.app/)

PersonaFit is a Streamlit web application designed to help you find the perfect fitness exercises based on your individual preferences and goals. Leveraging a comprehensive dataset of fitness exercises, PersonaFit allows you to filter and explore a wide range of activities to build a workout routine that truly fits *you*.

## ✨ Key Features

* **Intuitive Filtering:** Easily filter exercises by body part, equipment required, and level of difficulty.
* **Detailed Exercise Information:** Get a clear understanding of each exercise with its name, the targeted body part, necessary equipment, and difficulty level.
* **Personalized Exploration:** Discover new exercises that align with your specific fitness needs and available resources.
* **Streamlit Powered:** Enjoy a user-friendly and interactive experience powered by the simplicity and efficiency of Streamlit.

## 🚀 Getting Started

Ready to find your perfect fit? Follow these simple steps to run PersonaFit locally:

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/AkibDa/PersonaFit.git](https://github.com/AkibDa/PersonaFit.git)
    cd PersonaFit
    ```

2.  **Install Dependencies:**
    Make sure you have Python installed on your system. Then, install the necessary libraries using pip:
    ```bash
    pip install -r requirements.txt
    ```

3.  **Run the Streamlit App:**
    Navigate to the `PersonaFit` directory in your terminal and run the Streamlit application:
    ```bash
    streamlit run app.py
    ```

4.  **Open in Your Browser:**
    Streamlit will automatically open the app in your default web browser. If it doesn't, you can find the local URL in your terminal (usually something like `http://localhost:8501`).

## 💾 Data Source

This application utilizes the "Fitness Exercises Dataset" available on Kaggle:

[Fitness Exercises Dataset](https://www.kaggle.com/datasets/omarxadel/fitness-exercises-dataset)

This dataset provides a rich collection of exercises with information on body parts, equipment, and difficulty levels.
